# AI Semester Project 2026

Uninformed search in JavaScript: Social Golfers, Sudoku, Latin Square, and search trees.

No external libraries. Requires [Node.js](https://nodejs.org/).

## Run

From this folder:

```bash
node index.js
```

The menu asks for a problem number. You can also start one directly:

```bash
node index.js 1    # Social Golfers
node index.js 2    # Sudoku
node index.js 3    # Latin Square
node index.js 4    # Search Trees
node index.js 5    # all of them
```

Or use the npm scripts:

```bash
npm run golf
npm run sudoku
npm run latin
npm run trees
```

Latin Square accepts the order `n` (the assignment example is 5):

```bash
node src/03-latin-square.js 5
```

Each program prints the model (variables, domain, constraints), the objective function, the search landscape, and then the search itself.

## Social Golfers

Thirty-two players, eight groups of four, can play for **at most 10 weeks** if no pair shares a group more than once.

Eleven weeks are impossible: each player meets 3 new partners per week and there are only 31 other players (`11 × 3 = 33`). The 10-week schedule built by the program has objective value `f = 0`. Week 1 matches the assignment example. Group 8 is `{16, 17, 18, 19}`.

The same depth-first search also builds a schedule on its own for 6 players (5 weeks) and for the 32-player problem over 5 weeks.
